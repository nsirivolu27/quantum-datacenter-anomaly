What an intruder tries, and what the data center sees

The same lab, read as a security story. Each page is one move an attacker makes, the sensor that notices, and the layer that stops it. Every move here is a scripted, harmless imitation inside an isolated network; the sensors and the refusals are real.

Move one: look for open doors

An intruder on a machine tries ports on its neighbors to learn what is there. Seven knocks on a decoy, then a fake login on the one door that answers.

2

Move two: check in on a schedule

Malware phones home at regular intervals. So does a harmless status script. The lab flags the rhythm and labels it look closer, not caught.

3

Move three: borrow the GPU and move data out

Heavy compute with no approved job, while large uploads go to the unapproved machine. Two sensors see two halves. The lab joins them only because the same node and the same five seconds are involved.

4

Move four: swap the model for a poisoned one

Three layers stand between an intruder on the worker and a changed model file. Each one fails loudly on its own.

5

Move five: edit the evidence

The last thing an intruder wants is a clean record of what happened. Two protections hold, one is admitted to be weak.

6

Six layers, and what each one can and cannot do

No single layer is trusted to be enough. That is the whole idea of defense in depth.

7

From a finding to a decision

Nothing here quarantines a machine or changes a firewall by itself. A finding is a well-labeled question for a person, with the raw lines attached.

8

What is imitation, what is real, and what a cloud version would add

The attacker is a script

Port knocks, a fake login, heartbeats, dummy uploads, a refused write. Enough to exercise every sensor, nothing that could hurt anything.

The defenses are real

The camera captures actual traffic, the decoy logs actual touches, the kernel actually refuses the write, and the seal actually breaks.

What the cloud would fix

Real identities per role, a signing key nobody can read, evidence storage nobody can delete, and an audit of every API call. Written up, not built.
