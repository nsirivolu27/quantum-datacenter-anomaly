Inside a data center, one second at a time

A picture book of how a server is watched, how odd behavior is caught, and how the valuable files are kept from being changed quietly. Built from a working lab, drawn page by page.

1

A server never stops talking about itself

Every second: how busy the GPU is, how hot, how much power, and which computers it is connected to.

2

Four listeners, each with one job

A thermometer, a traffic camera, a fake door, and a visitor log for the file cabinet. None of them talk to each other.

simulated by a scriptrealrealkept only on the host computer
3

Now imagine the whole hall doing that

Each server keeps its own listeners next to it. Records flow into a collector that only ever sees clean, time-stamped lines, so adding servers adds lines, not new kinds of work.

1 / sGPU readings per server
~0.6 / sconnections per server in the lab cycle
4,000lines the collector reads per source, per pass
1,500evidence records kept in one snapshot
4

Before anything is judged, it is cleaned

Old lines, duplicates, broken lines, and lines from other machines fall out. Only what is left reaches the rules.

5

Rules are simple questions with numbers in them

Each rule watches one thing. Two of them watch two things at once, and only count when the same machine and the same few seconds are involved.

from the thermometerfrom the camerafrom the fake doorfrom the cabinet log
6

Every finding lands in one of three bins

Broken, look closer, or someone did something they should not. The bins never merge, and each finding says what it cannot prove.

Broken

A cooling fault. Fix it fast. Nobody is attacking anything.

Look closer

Heavy work with no approved job, a steady heartbeat, a refused request. A person decides.

Should not have happened

Touching the decoy, probing ports, a changed model file. Still not proof of who or why.

7

Two minutes in the lab, as it really ran

Watch the playhead. Findings appear only when the sensors earned them. The approved job on the left produces nothing, on purpose.

8

The file cabinet, and four ways it stays honest

Datasets, trained models, settings, and evidence. The goal is not to hide them. It is to make a quiet change impossible to miss.

9

Three things no sensor here can see

A picture is only honest if it shows the blind spots too.

What was inside

The camera sees the size of the envelope, both directions added together, never the letter.

Which program did it

The same machine, the same five seconds. Whether one program did both is a question, not a fact.

Who a program really is

Names on the guest list are labels. Real identity would need a scheduler or login system the lab does not have.
