Storage and scope

The collector reads the last 4,000 lines from each source. Exports contain up to 1,500 original evidence records. Disk logs continue growing. This lab observes one container's network interface; it does not monitor the whole host or provide production SIEM retention.

Automated containment, AWS integration, real GPU collection, and production authentication are not implemented. See docs/09-local-security-lab.md and docs/10-gpu-metrics-and-security.md in the repository.
