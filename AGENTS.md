# Repository instructions

## Commit attribution

- Do not add Codex, Claude, or other AI/tool attribution tags to commit subjects,
  bodies, author or committer identities, or commit trailers.
- Do not add AI `Co-authored-by` trailers, generated-by notices, or tool signatures.
- Describe the actual changes and verification results in plain commit messages.
- Use this repository's neutral identity: `Project Maintainer`
  <project-maintainer@example.invalid>. Configure it locally for this repository;
  do not change global Git identity settings.
- Check the final message and author/committer metadata before committing. Apply
  this rule to commits, merges, and squashes created for this repository.
